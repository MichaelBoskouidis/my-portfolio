# my portfolio

my personal website, built with html and tailwind css.

🔗 **live demo:** [https://github.io](https://github.io)

## features
- a bit about me, my background, and what i like
- links to my social media and other projects
- responsive design that works on both desktop and mobile
- clean and modern layout styled with tailwind

## built with
- html5
- tailwind css
- hosted on github pages

## how to run locally
1. clone the repository:
   `git clone https://github.com`
2. open the project folder and double-click `index.html` to view it in your browser.
